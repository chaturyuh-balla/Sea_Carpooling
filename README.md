SEA (Safe • Easy • Affordable) is a full-stack web-based carpooling system designed to simplify ride sharing and reduce travel costs. 
The application allows users to create accounts, log in securely, and manage their profiles. Users can create rides by entering details such as source, destination, date, time, available seats, and travel cost, which is automatically calculated based on distance and fuel consumption.
Other users can search for available rides based on location and join them if seats are available. The system promotes efficient resource usage and eco-friendly transportation by encouraging shared travel. 
The frontend is developed using React.js with a clean and user-friendly interface, while the backend is built using Spring Boot with RESTful APIs and MySQL for data storage. 
This project demonstrates the implementation of a complete full-stack application with user interaction, real-time data handling, and modular architecture.

🌟 Features
- 🔐 User Authentication (Signup & Login)
- 🚘 Create Ride with details (source, destination, date, time, cost)
- 🔍 Search Available Rides
- 🤝 Join Ride (based on seat availability)
- 👤 User Profile Management
- 💰 Automatic Cost Calculation (based on distance & fuel cost)

🛠️ Tech Stack

### Frontend
- React.js
- Axios
- CSS (Custom Styling)

### Backend
- Spring Boot
- REST APIs

### Database
- MySQL
